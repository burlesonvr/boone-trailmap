# Boone Fork Secret Spot Route

This map shows a hiking route from the Old Turnpike Road area to a quiet spot along Boone Fork near Hebron Falls. I chose this route because I wanted to map a place that I am familiar with and make the map useful for someone exploring the area. I used Leaflet and an Esri topographic basemap to create the map. The route and four points are stored as GeoJSON data. When you hover over each marker, the name of the location appears. I also made the River Crossing marker clickable so that it takes you to the National Park Service bear safety page. I first created the route using Google Maps and converted it from GPX to GeoJSON using geojson.io. I then used HTML, CSS, JavaScript, and Leaflet to put everything together and customize how the finished map looks.
